## What's new
- **AI prompt is now followed strictly:** only moments that really match your prompt are returned (best match first). Nothing unrelated is added to reach the clip count - if only 2 match, you get 2. The prompt can be written in any language; the AI first understands its meaning, even when the video is in another language.
- **Preview picture:** the random stock photo shown when the window cannot draw a video is gone - a real still of your video is taken with FFmpeg instead. Every preview copy is now a short part (90 s from around 15 % of the video, slider to change it) - that includes transport-stream files renamed .mp4 - with a popup saying so. If the preview shows no picture 15 seconds after the Studio page opens, it switches to a short part by itself.
- **Better hooks:** the AI is told never to copy a line the speaker says or write a first-person line. Every hook is checked afterwards; one that is copied speech, first person or an unfinished sentence is rewritten by the AI in a second pass, or built from the clip's title if no AI answers. Hook size/position logic is untouched.
- **Heavy-video preview, done properly:** a video the window plays fine is previewed whole. Only a heavy one (4K, AV1, HEVC, or not playable) gets a 90-second preview part taken from around 15 % of the video (where people are usually talking), made in the background. A small popup says so, and the Studio page has a "Preview part" slider + "Show this part" button to pick another part. Clips are always cut from the full video. The blurred backdrop copy of the video now starts only after the sharp one has its first picture, and the thumbnail is shown until then, so the black flash is shorter.
- **Closing the window no longer throws away a running project:** pressing the X while a project (or a batch edit) is running now asks "Keep working / Close and stop". And when the app is closed anyway, the saved progress (transcript, analysed clips, every finished clip) is always kept - before, the odd error messages that appear while the app shuts down could make the engine delete everything, so "Resume" started from zero. A failed run also keeps its progress once the transcript or any clip is done, so Resume can continue it.
- **Hook size in the finished clips now matches the editor (real fix):** the video render handed the hook font's measurements to the size checker in the wrong shape, so the checker never knew the font and silently used a rough guess that shrank every hook to about 60 % of the size you set. The render now measures the real font, so a hook keeps the size you chose and only shrinks when it would really leave the screen or run into the footage. The preview text also no longer uses tighter letter spacing than the video.
- **Videos that stayed black in the preview:** some ".mp4" files are really transport streams (typical for Dropbox / broadcast exports) - VLC plays them, this window cannot. They are now detected and re-wrapped into a real MP4 without re-encoding (seconds, full length). Heavy 4K / AV1 / HEVC sources get a small preview copy of their first 2 minutes made in the background (full-length copies took far too long on weaker computers), and the Studio page tells you while it is being made. Clips are always cut from your original file.
- **Import no longer makes you wait, and the preview picture is decoded safely:** the window's video player now decodes with the processor instead of the graphics driver (older Intel drivers showed black or colour-garbled frames, also in the small thumbnails). When a video needs a small preview copy, you can carry on at once and the copy (now 540p, 30 fps) is made in the background and swapped in when ready. Only a file the window cannot read at all is still prepared first.
- **Update download can no longer produce a broken installer:** the fast multi-piece downloader could write a piece twice or skip bytes when the connection dropped, which gave the "NSIS Error: Installer integrity check has failed". Every piece is now fetched again from its own start, written at its exact position, and the finished file is checked against the size and SHA-256 that GitHub publishes. A file that does not check out is downloaded again as one plain stream, and the app only closes for the install when the file is proven good.
- **Preview fix:** an old "cancel" could silently block the preview-copy maker (so heavy videos stayed black). Fixed. If a preview copy still cannot be made, the Studio page now shows the reason in red.
- **Preview of heavy videos:** if the window opens a video but cannot draw its picture (black preview), or the file is 4K / above 60 fps, the app now makes a small preview copy automatically. The clips are still cut from your original file.
- **Graphics-card mode does more of the work:** the source video is decoded on the GPU, NVIDIA cards also resize the picture on the card (only the small result goes back to the processor), the blurred backdrop is made at a quarter of the size (looks the same, much less processor work), and up to 3 clips render side by side. "Both" runs 2 clips on the card and 1 on the processor, whoever is free takes the next clip. Captions, effects, overlays and the behind-the-person cut-out have no GPU version in FFmpeg and still use the processor. Every step falls back automatically if a driver cannot do it.
- **Edit clips is now a real background pipeline:** applying changes to many clips uses the same graphics-card + processor workers as the first render (2-3 clips at a time on a strong PC), shows a pipeline-style progress page with only the steps that matter plus Pause / Cancel Pipeline, and you can watch your clips meanwhile. The Edit clip button is unavailable until it finishes or is cancelled.
- **Faster renders on strong computers:** the render pool now runs more than one clip per device when the CPU has enough cores.
- **Updates download faster and can be cancelled:** the update is fetched in 8 pieces at once (shows MB/s); the cross cancels the download.
- **Fewer freezes / white screens:** ffmpeg runs at lower priority so the window stays smooth; if the graphics process crashes the app reloads and starts without GPU drawing next time.
- **Project name field in Studio** (empty = the video's name). Deleting a project now also removes its clipforge marker files.
- **Caption picker is smoother** (previews load only while visible; category pills respond instantly).
- **Translated captions sync better** (translated in short phrases tied to the spoken moments).
- **Behind-the-person captions:** crisper, slightly grown cut-out (no see-through hats/hair) and the big word can no longer rise out of the top of the clip.
- **More video formats in the preview:** videos the window cannot play (HEVC / 10-bit / MKV / AC3 sound …) now get a small preview copy automatically, so the preview plays; the clips are still cut from your original file.
- **Better AI titles, hooks and descriptions:** the writer now also reads a short digest of the whole video, uses stronger click-driven patterns (curiosity gap, specifics, first-word punch) and writes tighter two-sentence descriptions. It stays true to the clip.
- **Hook emoji option checked:** on = emojis in a row above the hook (preview and video), off = none. The preview now shows the same row.
- **Watermark: text + image together.** Pick "Text + image" to show both at once; each has its own position, opacity and size, and you can drag each one on the preview. Text opacity is now adjustable (the video and the preview match).
- **New caption style "Viral Duo Emoji":** two-line bold captions, the spoken word flips between red, green and yellow, with a contextual emoji under the text.
- The caption style picker's green outline now moves instantly; F12 no longer opens the inspector in the installed app.
- **Auto Hook now has a supervisor:** every clip's hook keeps your size and position as far as possible and only changes what is needed so it stays inside the screen, above (or below) the footage the way you placed it, and with the emoji not touching the text. The Studio / Edit Clip preview now keeps the chosen number of lines and uses the same placement as the render; the size slider maximum also respects the free space next to the footage.
- **Android app layout:** the app no longer scrolls sideways; headers, the Pro badge and the clips page fit the screen. The graphics-card / processor choice is hidden on the phone, and texts say "phone" and "Save clips to gallery" instead of "computer" and "folder". Heavy speech models are marked "Heavy for a phone".
- **Auto stock b-roll** (Video > B-Roll) with free Pexels / Pixabay keys (and paid Shutterstock / Storyblocks) in Settings > Stock footage.
- **Multi-speaker layout** switch (Preview & setup, Full Crop): two people side by side get half of the screen each.
- **Caption sounds**, optional **progress bar** and **Clean voice** (noise reduction).
- Edit Clip: caption picker opens on top, hook colours follow the same line / first words in every clip, and Apply shows its own progress window with Pause / Cancel.
- Hook size maximum fills the screen width. YouTube downloader made more reliable. "What's new" shows only the new version.
